Granary is a Windows 11 desktop client **compatible with [Silo](https://github.com/Silo-Server/silo-server) media
servers**. It browses your libraries in a calm, minimal interface and plays everything through **libmpv** with
**libplacebo** (`gpu-next` on Direct3D 11) instead of a browser video element.

## Why a native client

- **Direct play** of 4K HDR10 and Dolby Vision remuxes with hardware decoding: no browser codec limits.
- **Correct HDR on OLED desktop monitors**, also when Windows HDR is always on. Tone mapping targets the real peak
  brightness of the monitor the player is on.
- **Smooth motion** at high refresh rates and with VRR; the refresh rate is only changed when that helps.
- **Everything is restored.** Every HDR or refresh change is recorded before it happens and undone afterwards, even
  after a crash.
- **Opt-in receiver features**: bitstream passthrough, exclusive audio, channel layouts.

<Callout title="Status">
  Granary is a private test release (unsigned). Automated tests run against synthetic clips and a mock server on an
